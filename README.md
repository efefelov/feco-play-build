# ⚙️ FECO Play

**Игровая вселенная ФабрикиДВС** — симулятор завода по производству поршневых и газотурбинных двигателей внутреннего сгорания.

## 🎮 О проекте

FECO Play — это браузерная idle-tycoon игра, где вы:
- Строите завод по производству ДВС
- Настраиваете конвейерные линии
- Производите поршневые и газотурбинные двигатели
- Создаёте технику для 4 стихий применения

## 🔥🌍💧💨 4 Стихии

| Стихия | Продукция |
|--------|-----------|
| 🔥 **Огонь** | Сами двигатели внутреннего сгорания |
| 🌍 **Земля** | Карьерная, дорожно-строительная, сельхозтехника, Ж/Д техника, насосные установки |
| 💧 **Вода** | Суда и корабли всех типов |
| 💨 **Воздух** | БПЛА, самолёты, вертолёты |

## 🚀 Технический стек

- **Frontend:** HTML5 + CSS3 + Vanilla JS (Phaser.js 3 для игры)
- **Backend:** PHP 8.1+
- **База данных:** MySQL / PostgreSQL (в разработке)
- **Авторизация:** Сессии + OAuth (Яндекс, VK, Telegram)
